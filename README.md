# Lateania — a living world inside your terminal

A guide site for **Lateania**, the fantasy MUD door game living inside
[late.sh](https://late.sh), Mateusz Piórowski's SSH terminal clubhouse.

Live at **[hardlygospel.github.io/lateania-guide](https://hardlygospel.github.io/lateania-guide/)**.

Covers all seventeen classes, the fourteen lands from the King's Road to the
Shattered Archipelago, the five-skill gather-to-legendary crafting economy,
the sixty tameable beasts (ten of them rideable), and the Wildbound expansion
that pushed the level cap to 100.

This is a fan-built companion page, not an official late.sh project. To play,
just:

```
ssh late.sh
```

No client, no download.
